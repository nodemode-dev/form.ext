## package

Check, then build the deterministic .formpkg (sorted entries, fixed timestamps), with SHA-256 and size. Refused on contract errors (every host would refuse the package) and, unless anyway, on code errors. reproduce also rebuilds it with the kit's own formpkg command and compares the SHA-256; out saves a copy.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `id` | string | yes | The project id (projects lists them). |
| `reproduce` | boolean | no | Also run the reproducibility check. |
| `out` | string | no | Save the .formpkg to this file or folder. |
| `anyway` | boolean | no | Package despite code errors (never despite contract errors). Say so to the person. |

## run_in_app

Add the project's package folder to FormPortal's dev.json for its app, so the real app loads it live as a development extension and picks up every save. remove takes it out again, status only reports, open also opens the app.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `id` | string | yes | The project id (projects lists them). |
| `remove` | boolean | no | Take the project out of dev.json. |
| `status` | boolean | no | Only report whether it is listed and what the host would say. |
| `open` | boolean | no | Open the app afterwards (when FormPortal installed it). |

## publish

Build, sign with the publisher key (unless unsigned) and make the submission folder for formai.studio: the .formpkg, entry.json, a one-package extensions.json and a README. formportal also sends the package to FormPortal to install.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `id` | string | yes | The project id (projects lists them). |
| `url` | string | no | The https address the package will be served from (default: its formai.studio address). |
| `publisher` | string | no | The publisher key to sign with (default: the settings' publisher or the only key). |
| `passphrase` | string | no | The key's passphrase, when it has one. |
| `unsigned` | boolean | no | Do not sign. |
| `formportal` | boolean | no | Also send the package to FormPortal to install. |

## submit

Write the project into a folder in form.ext-registry's layout (extensions/[id]/ with package/, the source, package.json when there is one, README.md, LICENSE, CHANGELOG.md and a screenshot slot), run the registry's tools/check.py on it when a local registry checkout is set (else form.ext's own Check, and it says which ran), and give the git and gh commands that fork nodemode-dev/form.ext-registry, add the folder and open the pull request. It never pushes anything itself.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `id` | string | yes | The project id (projects lists them). |
| `checkout` | string | no | A local clone of nodemode-dev/form.ext-registry whose tools/check.py runs on the folder (saved as the setting registry.checkout). |
