# Demo credits

The demo ships no photographs, video, recordings or other third-party media. Everything it shows is made by the Form apps' own code or drawn by the page.

The code libraries bundled in `assets/formext.js` (CodeMirror 6 and Lezer, crelt, style-mod, w3c-keyname, all MIT) are those of the desktop interface and are listed with their licences in the repository's `NOTICE.md`.

The README screenshots in the repository's `assets/` folder are captures of this demo's own window: the sample projects, the simulated FormLit catalogue (file names and numbers only) and Golden Hour's drawn sun path. They hold no photograph.
